# Replace Skill Cost

Both Shops and Super Shops offer a random skill replacement: the UI picks a sinner and a skill slot for you, at these Cost values.

| Replacement | Cost |
|---|---|
| Skill 1 → Skill 2 | 45 |
| Skill 2 → Skill 3 | 75 |
| Skill 1 → Skill 3 | 120 |

Super Shops additionally offer "ID Skill Search": you pick which sinner and skill slot to replace instead of taking the random offer. This costs exactly double the random-offer price, still paid entirely in Cost (no Starlight involved).

| Replacement | Cost |
|---|---|
| Skill 1 → Skill 2 | 90 |
| Skill 2 → Skill 3 | 150 |
| Skill 1 → Skill 3 | 240 |
